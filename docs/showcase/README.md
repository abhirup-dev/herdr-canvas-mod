# Showcase

The diagrams in the README screenshots, drawn by an agent in a clean Herdr instance.

- Canvas blocks (editable Excalidraw): `herdr-draw canvas block put <id> canvas-architecture.md`, `canvas-sequence.md`.
  The sequence block's participant colors were set afterwards with `herdr-draw canvas update`.
- Pins (Mermaid, in the pane's Diagrams popup): `herdr-draw mermaid add --tab Shopfront <file>` for `pin-sankey.md` and `pin-state.md`.
